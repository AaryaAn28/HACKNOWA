# Data Confidence System

Reality Sculptor explicitly tracks the provenance and reliability of every piece of data in the World Graph. We never fake data or present guesses as facts.

## Five Confidence Levels

1.  **OBSERVED** (Highest):
    *   Direct measurements.
    *   *Examples*: Live SCADA sensor data, high-res survey grade GPS, recent LiDAR.
2.  **DERIVED**:
    *   Extracted from reliable engineering documents.
    *   *Examples*: Pipe diameter extracted from a clean CAD blueprint, building footprint from official city GIS.
3.  **ESTIMATED**:
    *   Inferred from heuristics or statistics, but highly probable.
    *   *Examples*: Interpolating pipe invert between two known manholes, assuming residential roof type based on neighborhood averages.
4.  **SIMULATED**:
    *   Output from an ML model or physical simulation.
    *   *Examples*: Traffic volume generated by an OD matrix model, flood depth from SWE solver.
5.  **UNKNOWN** (Lowest):
    *   No data available, placeholder values used to prevent crashes.
    *   *Examples*: Default pipe roughness if material is entirely unknown.

## Propagation Rules

When a calculation uses inputs of mixed confidence, the output confidence is generally bounded by the lowest confidence input.
*   `Capacity = f(Diameter [DERIVED], Slope [ESTIMATED])` -> `Capacity is ESTIMATED`.
*   If a simulation relies heavily on `ESTIMATED` data, the final result is flagged with a warning.

## Uncertainty Visualization

The frontend visualizes confidence:
*   High confidence data is rendered solidly.
*   Low confidence data (ESTIMATED/UNKNOWN) may be rendered as wireframe, semi-transparent, or with a warning icon.
*   Simulation results present ranges instead of single points when confidence is low.

## Example: Downstream Flood Range

*   **Input**: Drain capacity (Confidence: 55%, ESTIMATED based on age). Value: 0.5 m³/s ± 0.2 m³/s.
*   **Simulation**: Instead of simulating exactly 0.5 m³/s, the system runs an ensemble or sensitivity analysis.
*   **Output**: "Predicted downstream flood depth: 0.3m - 0.8m (due to uncertainty in upstream drain capacity)."

## Source Priority Hierarchy

When conflicting data exists, this hierarchy resolves it:
1.  Human Correction (User explicitly overrides)
2.  Live Sensor (OBSERVED)
3.  CAD/As-Built Blueprint (DERIVED)
4.  Scanned PDF Blueprint (DERIVED - lower confidence)
5.  Public GIS/OSM (DERIVED/ESTIMATED)
6.  Procedural Generation (ESTIMATED)
